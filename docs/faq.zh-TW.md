# 常見問題

[简体中文](faq.md) | [English](faq.en.md) | 繁體中文

## 啟動

**第一次啟動很慢。**
第一次要在本機建置後端和網頁、下載相依套件，一般 3–10 分鐘（看網速）。之後再啟動只要幾秒。

**開啟 http://localhost:8080 是空白或連不上。**
先看三個服務是不是都起來了：

```bash
docker compose ps
```

`backend` 那一列要是 `healthy`。不是的話看它的日誌：`docker compose logs backend --tail 50`。

**8080 連接埠被其他程式占用。**
建立一個 `.env`，寫 `QS_PORT=9090`（換成你想要的連接埠），再 `docker compose up -d`。

**頁面上方一直顯示「連線中」，沒有行情。**
多半是這台機器連不上幣安（有些地區和網路不行）。兩個辦法：

- 讓 Docker 走你的代理（Docker Desktop → Settings → Resources → Proxies）；
- 或者先用模擬行情看介面：`.env` 裡寫 `MARKET_SOURCE=sim`。模擬行情的價格是隨機產生的，只用來看功能。

只有現貨頁面提示「現貨行情中斷」、合約正常的話，是現貨的推送位址連不上：`.env` 裡寫 `BINANCE_SPOT_WS_URL=wss://data-stream.binance.vision:443` 再試。

**電腦睡眠以後打不開了。**
Docker Desktop 在有些電腦上睡眠後會結束。重新開啟 Docker Desktop，服務會自己起來，資料都在。

## 帳號

**註冊要信箱嗎？**
不用。註冊和登入只用帳戶名和密碼，註冊完直接進去。信箱在帳戶頁綁定（可選）：綁了以後，忘了密碼能用它找回，提醒也能寄到信箱。設定寄信信箱（`SMTP_*`，或在「系統」頁填）時，綁定要填一次寄到信箱的驗證碼。

**忘了登入密碼。**
登入頁點「忘記密碼？」，輸入帳戶名，驗證碼寄到這個帳戶綁定的信箱。沒綁信箱、或這台沒設定寄信信箱的話，在部署的那台電腦上執行 `docker compose exec backend qs reset-password 你的帳戶名`，會給你一個新的隨機密碼，登入後再改成自己的。

**忘了二級密碼。**
帳戶頁 → 二級密碼 → 修改 →「忘了二級密碼？」，輸入一次登入密碼（開了二次驗證的再輸入驗證器上的 6 位數），設一個新的就好，不用信箱。重設以後：所有裝置登出；交易所帳戶暫停開新倉（減倉、平倉、停利停損照常），用新的二級密碼重新開啟就恢復；會發一則提醒。只綁了錢包、沒有登入密碼的帳號：先在「登入方式」裡綁一個信箱和登入密碼，或者用下面的本機指令。

**我自己就是部署的人，二級密碼忘了、信箱也用不了。**
在部署的那台電腦上執行（信箱換成你的，也可以寫使用者編號）：
```
docker compose exec backend qs reset-trade-password you@example.com
```
二級密碼就清空了，所有裝置登出，交易所帳戶暫停開新倉；登入後到帳戶頁設一個新的（不用輸入舊的），再把交易所帳戶重新開啟。手機遺失、二次驗證登不進去時，同樣用 `qs reset-2fa you@example.com`。只有能操作那台電腦的人才能執行，網頁上做不到。

**二級密碼是做什麼的？**
防的是「已經進門的人」：有人坐到你登入中的電腦前，或者你自己一時衝動。會造成損失的操作需要它：串接交易所金鑰、開啟交易所帳戶、替交易所帳戶建訊號位址、關掉下單確認、關掉或放寬紀律鎖、刪除帳戶、修改「系統」頁的設定。往安全方向的（停機、收緊規則）和只動模擬交易的不需要。忘了可以輸入登入密碼重設，所以防「知道你登入密碼的人」靠的是二次驗證：串接真錢前建議開啟。裝在自己電腦上時，離開電腦就鎖定螢幕（Win+L）最有用。

**有管理員嗎？**
沒有。一台裝好的系統是一個人自己用的，這台上的帳號權限都一樣，誰也管不了別人的帳號。全域停機、系統設定、註冊開關、操作記錄都在右上角的齒輪（「系統」頁，「？」選單裡也有）裡，修改要二級密碼。第一個帳號以後預設不能自己註冊，要加帳號就在「系統」裡新增。

## 模擬交易

**模擬交易的數字可靠嗎？**
規則逐條按幣安 U 本位永續製作：手續費、保證金分級、強平與清算費、價格和數量限制、資金費按實際結算時間和費率。和幣安不一樣的地方在介面和文件裡寫明了（例如模擬交易沒有其他交易者，自動減倉排隊是估算的）。

**為什麼我的市價單晚了幾百毫秒才成交？**
模擬交易預設模擬「這台電腦到幣安」的實際網路延遲，單子按到達那一刻的委託簿成交。可以在帳戶頁的交易偏好裡換成某個地區，或者關掉。

**模擬資金虧光了。**
帳戶頁的模擬帳戶那一欄：「資金」直接加錢或拿走一部分（本金跟著變，加進來的錢不算獲利）；「重設」清空持倉重新開始，可以換個金額，舊紀錄歸檔保留；也可以再開新的。金額不限，不需要二級密碼。

**模擬交易的手續費能改嗎？**
能。帳戶頁模擬帳戶那一欄點「手續費」，按百分比填吃單、掛單費率（0 到 1%），例如按自己在幣安的 VIP 等級填。只影響之後的成交。預設是幣安一般用戶：吃單 0.05%、掛單 0.02%。

**大倉位強平是一次全平嗎？**
不一定，和幣安一樣：先撤掉委託，再平掉「剛好夠」的一部分，保證金夠了就停；不夠才全平。小倉位的維持保證金率比清算費率低，基本上都是整個平掉。

## 策略

**你們提供策略嗎？**
不提供，也不給買賣建議。這裡是讓你把自己的策略接進來驗證的地方：見[策略作者指南](strategy-guide.md)（簡體中文）。

**我的策略怎麼接進來？**
三種接法，依你已有的東西選（[詳細說明](strategies.md)，簡體中文）：

- 有 TradingView 警報或者能送一個 HTTP 請求：用 Webhook，一句話就行（「做多 BTC 30%」）。
  - TradingView 策略：在策略裡給每筆單寫 `alert_message`（比如 `"做多 BTC 30%"`），警報訊息填 `{{strategy.order.alert_message}}`。策略警報預設的那句（"buy @ 0.01 filled on …"）寫的是張數，這裡按資金的百分比下單，不認。
  - 品種寫 `BTCUSDT.P`（TradingView 的永續）時，buy / sell 就是合約的做多 / 做空；不寫 `.P` 的 buy / sell 是現貨。
- 自己寫程式：用 qsig/1 送目標倉位，附理由和信心，平台記錄、計算成績、產生驗證報告。
- 已經有一個針對幣安寫好的程式：把網址換成這裡的「和幣安一樣的 API」，它就跑在模擬交易上。

**別人的策略能直接操作我的交易所帳戶嗎？**
不能。交易所帳戶（真錢）只能跟隨你自己建立的策略；別人的策略只能跟到模擬帳戶上看效果。

**回測和模擬交易的結果會一樣嗎？**
用的是同一套撮合程式，但回測按 1 分鐘 K 線走，模擬交易按實際委託簿走，會有差異。驗證報告裡的「回測一致性」可以把你的策略實際送過的訊號拿去回測，兩邊並列比較。

## 實盤

**串接實盤安全嗎？錢會不會被轉走？**
軟體裡沒有任何提領和劃轉的程式碼；儲存金鑰時會檢查權限，開了提領或劃轉的金鑰直接拒絕。金鑰加密後存在你自己的資料庫裡。建議再到幣安那邊替金鑰設定 IP 白名單，並且先用幣安「模擬交易」的金鑰試。見[串接幣安實盤](live.md)（簡體中文）。

**主金鑰是什麼？要備份嗎？**
加密交易所金鑰用的那把鑰匙。沒設定時第一次啟動自動產生，存在 `qs-data` 資料卷裡。**要備份**：

```bash
docker compose cp backend:/data/master.key ./master.key.backup
```

遺失後已儲存的交易所金鑰和策略金鑰無法解開，只能重新串接。

**能放到公網的伺服器上給幾個人用嗎？**
能，但要先做這幾件事：設定 HTTPS（前面放一個反向代理）、設定寄信信箱、修改資料庫密碼、設好 `ALLOWED_ORIGINS` 和 `SITE_DOMAIN`。見 README 的「安全」。你部署、別人把金鑰填進來，你就是保管這些金鑰的人，這個責任在你。

## 其他

**資料在哪？怎麼備份？**
都在 Docker 的兩個資料卷裡：`qs-db`（資料庫）和 `qs-data`（主金鑰）。備份資料庫：

```bash
docker compose exec db pg_dump -U qs qs > backup.sql
```

**怎麼徹底刪除？**
`docker compose down -v` 會連資料卷一起刪除（帳號、模擬交易記錄、儲存的金鑰都沒了，無法找回）。

**怎麼升級？**
拉取新程式碼，然後 `docker compose up -d`（每次啟動都會按現在的程式碼建置，沒改動時用快取，半分鐘左右）。資料庫的表會自動升級。

**發現了問題，或者想加功能。**
見 [參與開發](../CONTRIBUTING.zh-CN.md)。安全問題請私下聯絡維護者，不要公開提出。
