# 回测

回测新建一个和模拟盘**同一个**的撮合引擎，把币安的历史数据一分钟一分钟喂进去。手续费、保证金分档、强平和清算费、止损止盈（按标记价或最新价触发）、限价单、资金费、交易所的下单频率限制，都是模拟盘那段代码。

## 数据

币安 U 本位合约的公开接口，不需要密钥：

- 1 分钟 K 线，最新价和标记价各一份。强平、按标记价触发的止损止盈看标记价，最新价的插针不会误打。
- 历史资金费结算记录，按真实费率收付。

一次最多 5 个品种、180 天、2 万条信号。

## 信号表

每行"时间,信号"。`#` 开头的行和空行跳过，第一行可以是表头。时间按 UTC：`2026-11-01 08:00`、`2026-11-01T08:00:00Z`、毫秒或秒的时间戳都行。

```
time,signal
2026-11-01 08:00,做多 BTC 30%
2026-11-01 20:00,平仓 BTC
2026-11-02 00:00,{"action":"short","symbol":"ETHUSDT","size":"20%"}
2026-11-03 00:00,{"instrument":"ETH-PERP","side":"buy","type":"limit","price":"2300","qty":"1","sl":"2200","tp":"2500"}
2026-11-04 00:00,{"instrument":"BTC-PERP","weight":0.3}
```

- 前三种和 TradingView 警报一样（见 [strategies.md](strategies.md)）。
- 最后一种是一张完整的委托：`type` 可以是 `market`、`limit`（加 `tif`：GTC / IOC / FOK / GTX）、`cond_market`、`cond_limit`（加 `trigger_px`）；`tp`、`sl` 随单止盈止损，`trigger_by` 选 `mark`（默认）或 `last`；`reduce_only` 只减仓。
- `{"instrument","weight"}` 是目标仓位（qsig/1 的写法）：这个品种的仓位调到"当时的权益 × 权重"，正数做多、负数做空、0 平仓；反手时先平再开。按信号时刻的最新成交价换算，和模型组合一样。
- 接进来的 qsig/1 策略，验证报告里"回测一致性"可以一键把它收到的目标仓位拿来回测，也能下载这张信号表（`GET /api/strategies/{id}/signal-table`），贴进回测页自己改参数。
- 现货信号（买入 / 卖出）在合约回测里不执行，结果里写明原因。

## 三种用法

**界面**："复盘 → 回测"。贴信号表，选时间、初始资金、杠杆、全仓 / 逐仓、延迟、滑点，运行。结果有收益、最大回撤、平仓笔数和胜率、盈利因子、夏普、手续费和资金费、强平；权益曲线叠"一直拿着第一个品种"和回撤；每笔交易；每条信号的结果（什么时候到交易所、执行了还是被拒、为什么）。

**命令行**（给写策略的人）：

```bash
cd backend
go run ./cmd/backtest -signals ../signals.csv -from 2026-10-01 -to 2026-11-01 \
    -initial 10000 -leverage 10 -latency 150 -out result.json
```

结果写成 JSON（字段和接口一样），终端打印汇总。

**接口**：`POST /api/backtest`（要登录），请求体：

```json
{"lines": "…信号表…", "from": 1793491200000, "to": 1794096000000, "initial": "10000",
 "leverage": 10, "mode": "cross", "latency_ms": 150, "slippage_bps": 0}
```

## 一分钟里怎么走

只知道开、高、低、收，所以每分钟分四步：开盘 → 先到的极值 → 另一个极值 → 收盘。收涨的 K 线先跌到最低再涨到最高，收跌的反过来。这是常用的保守假设：对多头止损来说，先走最低价。

信号按"发出时间 + 延迟"到交易所；落在两步之间的，按两步之间线性插值的价格成交，不会被推到这一分钟的极值上。

## 和真实交易不一样的地方

- **深度**：盘口按深度足够算，大单没有冲击成本。资金量大时设滑点（万分之几，每笔吃单额外付）。
- **一分钟里的顺序**：真实顺序不知道，用上面的保守假设。
- **限价单**：价格要穿过挂单价才算成交，不按排队位置算（偏保守：只碰到挂单价不成交）。
- **延迟**：默认 0；界面默认用你的"模拟下单延迟"。

这些也写在每次回测结果的最下面。

## 对过真实数据

2026-11-10 用 BTC、ETH 三天的信号对过：开仓价等于币安那一分钟的开盘价；平仓按买一（比开盘价低一个最小价格单位）；手续费 0.05%；两次 8 小时资金费按币安记录的费率收付。
