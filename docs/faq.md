# 常见问题

简体中文 | [English](faq.en.md) | [繁體中文](faq.zh-TW.md)

## 启动

**第一次启动很慢。**
第一次要在本机构建后端和网页，下载依赖，一般 3–10 分钟（看网速）。之后再启动只要几秒。

**打开 http://localhost:8080 是空白或连不上。**
先看三个服务是不是都起来了：

```bash
docker compose ps
```

`backend` 那一行要是 `healthy`。不是的话看它的日志：`docker compose logs backend --tail 50`。

**8080 端口被别的程序占了。**
建一个 `.env`，写 `QS_PORT=9090`（换成你想要的端口），再 `docker compose up -d`。

**页面顶上一直显示"连接中"，没有行情。**
多半是这台机器连不上币安（有些地区和网络不行）。两个办法：

- 让 Docker 走你的代理（Docker Desktop → Settings → Resources → Proxies）；
- 或者先用模拟行情看界面：`.env` 里写 `MARKET_SOURCE=sim`。模拟行情的价格是随机生成的，只用来看功能。

**电脑睡眠以后打不开了。**
Docker Desktop 在有些电脑上睡眠后会退出。重新打开 Docker Desktop，服务会自己起来，数据都在。

## 账号

**注册要邮箱吗？**
不要。注册和登录只用账户名和密码，注册完直接进去。邮箱在账户页里绑定（可选）：绑了以后，忘了密码能用它找回，提醒也能发到邮箱。配了发信邮箱（`SMTP_*`，或者在"系统"页里填）时，绑定要填一次发到邮箱的验证码。

**忘了登录密码。**
登录页点"忘记密码？"，输账户名，验证码发到这个账户绑定的邮箱。没绑邮箱、或者这台没配发信邮箱的话，在部署的那台电脑上运行 `docker compose exec backend qs reset-password 你的账户名`，会给你一个新的随机密码，登录后再改成自己的。

**忘了二级密码。**
账户页 → 二级密码 → 修改 → "忘了二级密码？"，输一遍登录密码（开了二次验证的再输验证器上的 6 位数），设一个新的就行，不用邮箱。重置以后：所有设备退出登录；交易所账户暂停开新仓（减仓、平仓、止盈止损照常），用新的二级密码重新开启就恢复；会发一条提醒。只绑了钱包、没有登录密码的账号：先在"登录方式"里绑一个邮箱和登录密码，或者用下面的本机命令。

**我自己就是部署的人，二级密码忘了、邮箱也用不了。**
在部署的那台电脑上运行（邮箱换成你的，也可以写用户编号）：
```
docker compose exec backend qs reset-trade-password you@example.com
```
二级密码就清空了，所有设备退出登录，交易所账户暂停开新仓；登录后到账户页设一个新的（不用输旧的），再把交易所账户重新开启。手机丢了、二次验证登不上时，同样用 `qs reset-2fa you@example.com`。只有能操作那台电脑的人才能运行，网页上做不到。

**二级密码是干什么的？**
防的是"进了门的人"：有人坐到你登录着的电脑前，或者你自己一时上头。会造成损失的操作要它：接交易所密钥、开启交易所账户、给交易所账户建信号地址、关下单确认、关掉或放宽纪律锁、删除账户、改"系统"页的设置。往安全方向的（停机、收紧规则）和只碰模拟盘的不要。忘了可以输登录密码重置，所以防"知道你登录密码的人"靠的是二次验证：接真钱前建议打开。装在自己电脑上时，离开电脑锁屏（Win+L）最管用。

**有管理员吗？**
没有。一台装的东西是一个人自己用的，这台上的账号权限都一样，谁也管不了别人的账号。全局停机、系统设置、注册开关、操作记录都在右上角的齿轮（"系统"页，"？"菜单里也有）里，改动要二级密码。第一个账号以后默认不能自己注册，要加账号就在"系统"里添加。

## 模拟盘

**模拟盘的数字靠谱吗？**
规则逐条按币安 U 本位永续做：手续费、保证金分档、强平和清算费、价格和数量限制、资金费按真实结算时间和费率。和币安不一样的地方在界面和文档里写明了（比如模拟盘没有别的交易者，自动减仓排队是估的）。

**为什么我的市价单晚了几百毫秒才成交？**
模拟盘默认模拟"这台电脑到币安"的真实网络延迟，单子按到达那一刻的盘口成交。可以在账户页的交易偏好里换成某个地区，或者关掉。

**模拟资金亏完了。**
账户页的模拟账户那一栏："资金"直接加钱或拿走一部分（本金跟着变，加进来的钱不算盈利）；"重置"清空持仓重新开始，可以换个金额，旧记录归档保留；也可以再开新的。金额不限，不要二级密码。

**模拟盘的手续费能改吗？**
能。账户页模拟账户那一栏点"手续费"，按百分比填吃单、挂单费率（0 到 1%），比如按自己在币安的 VIP 等级填。只影响以后的成交。默认是币安普通用户：吃单 0.05%、挂单 0.02%。

**大仓位强平是一次全平吗？**
不一定，和币安一样：先撤掉委托，再平掉"刚好够"的一部分，保证金够了就停；不够才全平。小仓位维持保证金率比清算费率低，基本都是整个平掉。

## 策略

**你们提供策略吗？**
不提供，也不给买卖建议。这里是让你把自己的策略接进来验证的地方：见[策略作者指南](strategy-guide.md)。

**我的策略怎么接进来？**
三种接法，按你已有的东西选（[详细说明](strategies.md)）：

- 有 TradingView 警报或者能发一条 HTTP 请求：用 Webhook，一句话就行（"做多 BTC 30%"）。
  - TradingView 策略：在策略里给每笔单写 `alert_message`（比如 `"做多 BTC 30%"`），警报消息填 `{{strategy.order.alert_message}}`。策略警报默认的那句（"buy @ 0.01 filled on …"）写的是张数，这里按资金的百分比下单，不认。
  - 品种写 `BTCUSDT.P`（TradingView 的永续）时，buy / sell 就是合约的做多 / 做空；不写 `.P` 的 buy / sell 是现货。
- 自己写程序：用 qsig/1 发目标仓位，带理由和信心，平台记录、算成绩、出验证报告。
- 已经有一个对着币安写好的程序：把地址换成这里的"和币安一样的接口"，它就跑在模拟盘上。

**别人的策略能直接操作我的交易所账户吗？**
不能。交易所账户（真钱）只能跟你自己建的策略；别人的策略只能跟到模拟账户上看效果。

**回测和模拟盘的结果会一样吗？**
用的是同一套撮合代码，但回测按 1 分钟 K 线走，模拟盘按真实盘口走，会有差别。验证报告里的"回测一致性"可以把你的策略实际发过的信号拿去回测，两边摆在一起看。

## 实盘

**接实盘安全吗？钱会不会被转走？**
软件里没有任何提现和划转的代码；保存密钥时会检查权限，开了提现或划转的密钥直接拒绝。密钥加密后存在你自己的数据库里。建议再在币安那边给密钥设 IP 白名单，并且先用币安的"模拟交易"密钥试。见[接币安实盘](live.md)。

**主密钥是什么？要备份吗？**
加密交易所密钥用的那把钥匙。没配时第一次启动自动生成，存在 `qs-data` 数据卷里。**要备份**：

```bash
docker compose cp backend:/data/master.key ./master.key.backup
```

丢了以后已经存的交易所密钥和策略密钥解不开，只能重新接入。

**能放到公网的服务器上给几个人用吗？**
能，但要先做这几件事：配 HTTPS（前面放一个反向代理）、配发信邮箱、把数据库密码改掉、设好 `ALLOWED_ORIGINS` 和 `SITE_DOMAIN`。见 README 的"安全"。你部署、别人填密钥进来，你就是保管这些密钥的人，这个责任在你。

## 其他

**数据在哪？怎么备份？**
都在 Docker 的两个数据卷里：`qs-db`（数据库）和 `qs-data`（主密钥）。备份数据库：

```bash
docker compose exec db pg_dump -U qs qs > backup.sql
```

**怎么彻底删掉？**
`docker compose down -v` 会连数据卷一起删（账号、模拟盘记录、存的密钥都没了，找不回来）。

**怎么升级？**
拉新代码，然后 `docker compose up -d`（每次启动都会按现在的代码构建，没改动时用缓存，半分钟左右）。数据库的表会自动升级。
