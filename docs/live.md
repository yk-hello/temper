# 接币安实盘

接的是**你自己的**币安 U 本位合约账户。钱一直在你的币安账户里，这个软件不经手，代码里没有提现和划转。

## 建密钥

1. 币安 → API 管理 → 新建 API 密钥（系统生成）。
2. 只勾选 **允许合约**。**不要**勾选提现、内部划转、万向划转：开了这些权限的密钥会被拒绝保存。
3. 建议限制访问 IP，填部署这个软件的服务器的公网 IP。
4. 账户要用**单向持仓**（币安合约 → 偏好设置 → 持仓模式）。

想先用假钱试：币安的合约测试网已经并进"模拟交易（Demo Trading）"。登录币安，进"模拟交易"，在 API 管理里单独建一把密钥（勾选合约权限），接入时选"币安模拟交易"。接口地址是 `https://demo-fapi.binance.com`，推送是 `wss://demo-fstream.binance.com`（币安开发者文档 General Info 页）。

## 接入

"账户 → 交易所账户 → 接入币安"：填 API Key、Secret Key、二级密码。保存前会向币安查一次权限，开了提现或划转、没开合约、双向持仓都会说明原因并拒绝。接入以后在币安那边改成了双向持仓，下单会被交易所拒绝，界面会说明要改回单向。

接入后还要"开启下单"（再输一次二级密码），才能下单。

## 安全设计

- 密钥用 AES-256-GCM 加密存在数据库里，主密钥只在服务器上（环境变量 `QS_MASTER_KEY`，或者第一次启动自动生成的 `/data/master.key`），不进数据库。界面和接口只显示密钥的头尾几位。
- 用哪个账户交易，全站只在顶栏切换。交易所账户的标签和模拟账户颜色不同；切到交易所账户要确认一次；真钱账户的下单按钮写"实盘买入"。
- 下单确认默认打开，可以在"账户 → 交易所账户"那一行关，关要二级密码；打开不用。
- 纪律锁对交易所账户一样生效。
- 一把密钥只对应一个账户（两个账户共用一个交易所账户，仓位会打架）。
- 停用账户只是这里不再管理；币安上已有的仓位和委托不会被平掉或撤掉。
- 删账户时，密钥和本地记录一起删；建议同时到币安把这个 API 密钥删掉。

## 以币安为准

余额、仓位、委托以币安为准：收到币安的推送时、以及每 15 秒各对一次账（每次约 60 的请求权重，币安上限每分钟 2400）。账户推送走币安 2026 年起的新地址 `/private/ws/<listenKey>`（旧的 `/ws/` 在 2026-04-23 下线）。两次对账之间，浮动盈亏按实时标记价算。推送断开时交易页有一行说明，后台自动重连。

成交和资金费会存到本地，复盘、高光、纪律锁都能用。

## 和模拟盘的差别

| | 模拟盘 | 交易所账户 |
| --- | --- | --- |
| 撤单后 5 秒内撤回 | 有 | 没有（交易所撤掉的单撤不回来） |
| 改没触发的条件单 | 直接改 | 撤了重下（币安不支持改），编号会变 |
| 随单止盈止损 | 挂在委托上 | 成交后挂成整仓的条件单 |
| 分批下单、追价、TWAP、冰山单、按成交量比例、跟踪止损、分批止盈 | 有 | 暂时没有 |
| 机器人 | 有 | 暂时没有 |
| 策略跟随（qsig/1） | 有 | 有：开启时要二级密码，账户要先确认过"这是真钱"；分配金额、最大亏损、杠杆上限照样管着，亏到最大亏损自动平仓并停止；账户里已有的同一品种仓位会被当成跟随的仓位一起调整，最好用只给这个策略用的子账户 |
| 拒单原因 | 带具体数字（差多少保证金） | 币安的错误码翻成说明，交易所不给的数字不写 |
| 下单延迟 | 模拟（可选地区） | 真实网络 |
| 下单确认 | 可以按类型关 | 默认每笔确认；可以关，关要二级密码 |

## 支持的范围

币安 U 本位永续、单向持仓。条件单走币安 2025-12 起的 Algo 接口（`/fapi/v1/algoOrder`）。
